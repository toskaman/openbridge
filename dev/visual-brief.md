# Visual redesign brief for Meta Muse Spark 1.3

OpenBridge is a local-first device evidence workspace. Current UI has a charcoal sidebar, ivory title, orange discover action, device inventory, trust boundaries and inspection evidence. The working MVP contains only a SIMULATED Android fixture. We are adding a separate, opt-in USB Android read-only inventory; offline and unauthorized states must be clear. No hardware writes or Undo are available.

Propose a distinctive, accessible redesign for an engineering instrument, with a concise English UI. Keep existing HTML element IDs: discover, device-count, device, boundaries, evidence, report, status. Distinguish demonstration from real USB without implying connection or inference success. Include a clear mode selector and always-visible model/credit state. Avoid invented metrics and any fake live devices. Use vanilla HTML/CSS/JS, no fonts or external assets.

Return a concrete design rationale, palette, typography, layout at 390 and 1440px, exact UI labels and CSS recommendations. Keep under 1200 words. This is development design assistance, separate from shipped runtime inference. Never generate or request credentials or real device identifiers.
