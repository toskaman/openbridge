Run the tests:

```sh
python -m unittest tests.partners.test_esphome_light -v
```

Validate on hardware (needs an ESPHome device with `web_server:` in its YAML on the same LAN):

```sh
GET  http://<device>/light/<id>          # compare with _parse_power/_parse_brightness
GET  http://<device>/device-info         # compare with the firmware fact
POST http://<device>/light/<id>/turn_on  # {"brightness": 128}, then read back
POST http://<device>/light/<id>/turn_off
POST http://<device>/light/<id>/toggle
```

Then run the suite with `EsphomeLightTransport('<device>', '<id>')`, copy any quirk (ranges,
delays, extra fields) into the emulator, and record the run in `docs/DEVICE_EVIDENCE.json`.
