Run the tests:

```sh
python -m unittest tests.partners.test_openwrt_router -v
```

Validate on hardware (needs an OpenWrt router with `luci-mod-rpc` on the same LAN; use HTTPS when
the router serves it, `OpenwrtRouterTransport(host, password=..., use_https=True)`):

```sh
POST http://<router>/cgi-bin/luci/rpc/auth     # {"method":"login","params":["root","..."]} -> token
POST http://<router>/cgi-bin/luci/rpc/sys      # {"method":"uptime","params":[token]}
POST http://<router>/cgi-bin/luci/rpc/network  # {"method":"get_wan_status","params":[token]}
POST http://<router>/cgi-bin/luci/rpc/dhcp     # {"method":"leases","params":[token]} (else fs.read /tmp/dhcp.leases)
```

Compare each answer with `read()`, copy quirks into the emulator, and record the run in
`docs/DEVICE_EVIDENCE.json`. WAN/load/leases stay best-effort; only uptime is required.
