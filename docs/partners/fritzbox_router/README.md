Run the tests:

```sh
python -m unittest tests.partners.test_fritzbox_router -v
```

Validate on hardware (needs a FRITZ!Box with a box user on the same LAN; TR-064 lives on port 49000):

```sh
POST http://fritz.box:49000/upnp/control/deviceinfo      # DeviceInfo.GetInfo -> uptime, model, firmware
POST http://fritz.box:49000/upnp/control/wanipconnection1 # WANIPConnection.GetStatusInfo
POST http://fritz.box:49000/upnp/control/hosts            # Hosts.GetHostNumberOfEntries
POST http://fritz.box:49000/upnp/control/wlanconfig1      # WLANConfiguration.GetTotalAssociations
```

Compare each answer with `read()`, copy quirks into the emulator, and record the run in
`docs/DEVICE_EVIDENCE.json`. WAN/hosts/Wi-Fi stay best-effort; only uptime is required.
