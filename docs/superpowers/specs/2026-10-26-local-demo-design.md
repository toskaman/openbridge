# Local demo design

User authorized the project start and proposed phase-one scope on 26 October 2026 after the scheduled 16:00 UTC kickoff. Organizer start is participant-confirmed, not independently verified here.

Build a dependency-free Python localhost service with a static browser interface. Discovery returns a conspicuously SIMULATED Android fixture only. A deterministic inspection reports provenance and capability limits. Hardware writes remain unavailable. No model inference is claimed in this phase.

Bind to 127.0.0.1. Validate Host for every request; mutating requests require exact Origin and a random per-process CSRF token. Cap request size and refuse unsupported operations. Serve only explicitly mapped static files. No network scanning or device access.

Interface: dark instrument panel, warm ivory typography, orange action accent, persistent simulation status, device facts and timestamped inspection evidence. Responsive layout with keyboard-accessible controls and live status announcements.

Verify through unit and HTTP integration tests, browser discovery/inspection, narrow and desktop viewport screenshots, clean clone, and static preparation-side audits. Real inference, Android access and physical rollback remain NOT TESTED.
