# Supervised Meta runtime

Add one actual product recommendation path using synthetic demo facts only. Physical device data stays local. The browser never receives API credentials. Model output is an advisory JSON object and cannot change hardware.

RuntimeModelBroker pins the official HTTPS Meta endpoint and muse-spark-1.3. Require a short-lived, externally verified promotional-credit observation. No observation means no call. Enforce a durable SQLite reservation of $0.10 before every request, with at most $0.20 per supervised permit and $1 total in this prototype. Keep at least $1 of the observed free balance unused. Do not refund ambiguous failures or retry calls automatically. Default installations have no permit and remain blocked.

This is a conservative local guard, not a provider billing hard cap. It cannot observe spending from other account keys. The supervised operator must recheck the actual dashboard before issuing a fresh permit; unattended account-wide credit verification is not available.

Requests contain a fixed synthetic fact allowlist. Response identity must match; evidence references must exist; action must be inspect_only. Reject malformed, oversized, non-Meta and executable output. Record sanitized request identity, model, usage and estimated cost. Test missing/stale credit observations, durable limits, malformed output, timeouts and unknown inputs before a supervised live call.
