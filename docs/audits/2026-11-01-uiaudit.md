## Fixes (functional clarity first, design identity preserved)

1. Device-card facts ran together ("72%Synthetic battery"): added missing
   `.device-card .facts` stat-row styles (`theme/app.css`).
2. Finish dialog ran title into detail ("Screen timeoutAudit Pixel 8"):
   stacked `#finish-list` label rows (`theme/app.css`).
3. Explore showed backend jargon with no path forward ("Explore failed: No
   graph yet; execute bounded_discovery first"): friendly empty state with a
   working Discover CTA (`explorer.js`).
4. Topology list ignored the text filter while Cards applied it: the shell now
   filters tree rows DOM-side (matching rows + parents stay) on input and on
   every re-discovery (`shell.js`).
5. Degraded providers (OFFLINE/ERROR/STALE) were invisible unless the
   "Discovery sources" details was opened: warn chip after the meta line
   ("BLE, RELAY degraded", details in title), and OFFLINE/STALE join the
   blocked styling in the sources list (`app.js`).
6. Ask tier pills overflowed 390 px viewports (single nowrap pill wider than
   the screen): pills may wrap (`theme/command.css`).
7. Truncated transaction chips (`tx-audit-re…`) collide: full id in `title`
   (`shell.js`).
8. Inspection timestamp carried microseconds: trimmed to seconds (`app.js`).
9. Journal failure duplicated ("Simulated journal unavailable: Simulated
   transaction journal unavailable"): prefix dropped when the message already
   names the journal (`app.js`).
10. Topology category chip "ISP ROUTER API (E.G., FREEBOX OS / UPNP-IGD)"
    crowded every router row: short "Router" chip, full label kept in `title`
    and the detail table (`app.js`).

Checked and deliberately unchanged: stale inspector selection across
re-discoveries is already cleared (`shell.js` renderDevices); skill lifecycle
(Verified/Experimental/Discovered × Ready/Offline/…) and all consent gates
render as specified; 3440 px holds the 1880 max-width layout.
