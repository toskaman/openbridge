# Bonus award strategy (30 Oct 2026)

Eligibility is determined by the organizers, not by this document. Each
award below states what exists, what is missing, and what we refuse to fake.

## Best Agentic Use-Case
- Exists: multi-step cross-device orchestration (§7, merged `1e8066a`):
  capability probe → plan → approvals → execute → verify, with receipts.
  Live single-device run on USB phone (capture → hash-verified send →
  montage). Capability synthesis via §6 explorer + §9 facts.
- Baseline: deterministic rules baseline on the 1,000-turn eval kit
  (`docs/EVAL_1000_RULES_BASELINE.md`, 1.4% resolved, 0 sends). Model arms
  pending (see §11 roadmap).
- Missing: model-driven planning arm completing end-to-end runs on hardware.
- Do not claim until an orchestrated multi-step run is driven by a Meta
  model with provenance on file.

## Best Open Weight
- Exists: eligible open models installed and used locally (Llama 3.2 3B,
  Muse Glimmer 30B) for ablations and honest-negative evals.
- Missing: one completed user-facing feature whose inference is an
  eligible open-weight model with exact provenance (model id, weights
  hash, environment) recorded. Candidates: Glimmer visual read-back
  (`dev.visual_readback_tv`, run pending), Spark-tier ranking with
  recorded receipts.
- Installation alone is never claimed as eligibility.

## Best Creative Build
- Not pursued as an award. No Muse Wonder / Muse Image integration exists,
  and we will not add decorative model calls for eligibility.
- The creative story stands on its own: §8 dashboards synthesize control
  interfaces for arbitrary devices (deterministic today, labeled as such).

## Most Viral
- Ready: 180 s storyboard, real-capture discipline, homepage video/GIF slot,
  stills + receipts as backup evidence.
- Rules: no fabricated engagement, no automated votes, no misleading
  footage. Posting from the participant's accounts is owner-owned.

## Community Vote
- Ready: README (video/GIF + Meta sentence + 3 scenarios + evidence links),
  public gallery description = README one-liner + §8/§7 highlights.
- Comply with verified-account voting rules; gallery submission is
  owner-owned.

## Bottom line
Chase Agentic + Open Weight only through real proven runs. Viral/Community
materials are ready but owner-gated. Creative Build is honestly skipped.
