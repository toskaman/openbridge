# Partner voice profiles

Reviewed partner voice profiles (`*.json`, format `openbridge-voiceprofile/1`) ship here. An owner can add one in
`%LOCALAPPDATA%\OpenBridge\voice_profiles\`. See [docs/PARTNER_VOICE_MODEL.md](../../docs/PARTNER_VOICE_MODEL.md);
an example is in [docs/partners/examples/voice-profile.acme.json](../../docs/partners/examples/voice-profile.acme.json).
